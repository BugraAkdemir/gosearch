**Severity guide:**

- **CRITICAL** — data loss/corruption, security vulnerability, or the library is unusable for its primary purpose.
- **HIGH** — a real feature is broken or produces wrong results for a common case.
- **MEDIUM** — a real bug, but narrow (edge case, workaround exists).
- **LOW** — minor/cosmetic, or affects a rarely-used path.
- **TECH DEBT** — not a user-visible bug today, but a maintainability/scalability risk.
